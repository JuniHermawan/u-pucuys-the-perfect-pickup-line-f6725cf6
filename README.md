One short pickup line an AI agent could actually say out loud to a person: every simulation it runs ends the same way — asking you out. A genuine pickup line with a twist, in the machine's own voice, short enough for one breath, and easy to laugh off.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
